This isn't just the $10,000 curve divided by 10

The position caps (3% per trade, 50% aggregate, 25% per category) are expressed as percentages of current equity, so in principle a $1,000 run should trace the same shape as the $10,000 run. In practice it doesn't land on exactly the same numbers, because of one thing that does not scale with bankroll: liquidity depth caps. Fill sizes are capped by a proxy for real transactable volume near each crossing (a fixed number of shares from the public trade tape, not a percentage) — so a 3%‑of‑equity position that's $300 at the $10,000 scale occasionally exceeds an illiquid market's real depth and gets trimmed down, while the same 3% at the $1,000 scale ($30) almost never does.

The difference is real but modest; treat both as the same strategy, not two different ones.
